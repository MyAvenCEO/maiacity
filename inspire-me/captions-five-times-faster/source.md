So, let me show you the trick I use. First, open your Text+ and go to the size parameter. Right click it, choose expression and enter the expression you see on the screen. Then go to layout tab and change the layout mode to text box. And this is where the things get interesting. Now enable Fusion overlay view. And now instead of controlling the text size with slider, we are using the text box to control it. That means we can simply grab the text box and move and resize it directly in the viewer. And this is especially useful when you are working with multiple lines of text.

But there is one problem. You don't want to repeat this setup manually for every single Text+ because adding the expression doesn't really work on multiple titles at once. But there is another solution. If you don't know Snap Captions, it's a free plug-in that converts your captions into individual Text+ titles. So what I do is I create one Text+ with this setup already applied and this becomes my template. I then drag this template into the Snap Captions bin and run the app to convert my captions.
