HOW TO WRITE A DOC

A doc is a story of the Maia City vault like any other: its text is the source of truth, versioned in avenDB, and
its doc post is what the Docs page shows.

- A skill: the skill's SKILL.md first, frontmatter included (name, description), then each further file of the skill
  after a line `<!-- file: references/<name>.md -->`, so the skill can be written back to its files whole.
- A paper or an architecture document: its words as Markdown, its headings as the page's, each figure named by its
  caption. Where the site lays it out on a page of its own, the post's `page` points there.

Write in ASD-STE100 style where you can: short sentences, active voice, one word one meaning, each term explained at
its first use.
