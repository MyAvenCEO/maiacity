# Fonts

DM Sans and Fraunces (variable), copied from Fontsource 5.3.0 (`@fontsource-variable/dm-sans`, `@fontsource-variable/fraunces`)
so the site needs no font package. Each folder keeps its `LICENSE` (SIL Open Font License 1.1).

- `opsz.css` + the `*-opsz-normal.woff2` files: the faces the site loads (`maia/site/routes/+layout.svelte`).
- `*-latin-wght-normal.woff2`: the faces inlined into the view engine (`aven/kernel/sandbox/bundle.js`).
