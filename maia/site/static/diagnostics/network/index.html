Check this device’s connection

Run this on the iPhone or iPad you want to measure. Keep it in the foreground and pause other downloads. The result describes this device’s current connection.

One run uses up to 40 MiB of test downloads and 8 MiB of random upload data, plus at most 256 KiB to find the current public app file. Each transfer stops after 15 seconds. No account, passkey, vault, or stored app data is read or changed. Results stay on this page until you copy or save them. Test traffic goes to Maia City and Cloudflare, which receive ordinary connection information such as your IP address.

Mbps means millions of bits per second. These are bounded single-stream tests, not a promise of the connection’s maximum speed. The Maia file measures its public web-serving path; avenDB uses a different protocol. App sync also spends time preparing requests, checking edits, and saving data.
